# Ответы на вопросы

## 1. Что такое Git и для чего он используется?
Git - это своебразная библиотека для кода. Он нужен для того,чтобы все файлы были на своих местах;также он позволяет комфортно работать в команде и эксперементировать.
## 2. В чём разница между централизованными и распределёнными системами контроля версий?
В централизованных системах (типа SVN) есть один ГЛАВНЫЙ сервер-босс, а в распределённых (типа Git) — полная копия истории есть У КАЖДОГО УЧАСТНИКА на компе.
